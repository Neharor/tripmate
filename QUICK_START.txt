🆘 TROUBLESHOOTING:

❌ "Credentials not found"
   → Check .env file is in /backend/ directory
   → Verify no typos in AMADEUS_API_KEY

❌ "Amadeus SDK not installed"
   → Run: pip install amadeus

❌ "401 Unauthorized"
   → Double-check credentials from Amadeus dashboard
   → Make sure no extra spaces when copying

❌ Still seeing fake data
   → Restart backend (Ctrl+C then python3 main.py)
   → Look for "✅ Amadeus API connected successfully!"
